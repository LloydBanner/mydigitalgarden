There is a great mod for this [[Sources/XCOM 2\|XCOM 2]] that replaces the aliens with the Empire from [[Sources/Star Wars\|Star Wars]] called: [Advent to Empire](https://steamcommunity.com/sharedfiles/filedetails/?id=1395522281). This is the mod that changes the most within [[Sources/XCOM 2\|XCOM 2]] to be like [[Sources/Star Wars\|Star Wars]], but it doesn't do a lot of things. A lot of those other things have mods for them, but picking and choosing them all by yourself takes a long time. I have spent this time and created a Steam Workshop collection called [Star Wars Overhaul 2026](https://steamcommunity.com/sharedfiles/filedetails/?id=3752015134). This is as complete an overhaul as I could get working in 2026. There are a few tweaks I would like to do, but as a whole it runs really well with the occasional crash which can be fixed by reloading and then an unavoidable crash when you complete the game.

I think this changes as much as you can within the XCOM 2 modding framework to [[Sources/Star Wars\|Star Wars]] theming. All the cutscenes and dialogue are still from the base game, as are the maps and menus. Everything else is now Star Wars including character customisation, weapons, enemies, a Jedi class and music. I think this is currently the best you can find for a Star Wars Turn Based Strategy game, at least until [Star Wars Zero Company](https://store.steampowered.com/app/2075800/STAR_WARS_Zero_Company/) is released.

#### **Description from My Collection Page on Steam:**
A mod collection for a complete overhaul of XCOM 2 into a Star Wars game. I made this because I couldn't find any that were working in 2026 that had all the mods I wanted. Replaces all enemies with Star Wars enemies. Advent becomes the Empire, Lost become Death Troopers and there is a Nightsister Faction. Lots of Star Wars themed character customisation is added and avenger crew all have rebel attire. I think this makes a great Rebels vs Empire playthrough. It worked all the way until the final mission for me, the game seems to crash on completion of the final mission which I haven't resolved yet, but other than that the pack is very stable. I had a few other crashes on my playthrough but nothing major that wasn't fixed by relaunching the game and loading a save.  
  
Setup:  
- Click "Subscribe to all" on this collection (After unsubscribing from all other mods from XCOM 2)  
- Install XCOM 2 War of the Chosen  
- Download and install [Alternative Mod Launcher](steam://openurl_external/https://steamcommunity.com/linkfilter/?u=https%3A%2F%2Fgithub.com%2FX2CommunityCore%2Fxcom2-launcher) (May work without but I haven't tested)  
- Launch [Alternative Mod Launcher](steam://openurl_external/https://steamcommunity.com/linkfilter/?u=https%3A%2F%2Fgithub.com%2FX2CommunityCore%2Fxcom2-launcher) and enable all mods. (There will be some missing dependencies but these are not an issue and have been replaced with newer mods so ignore them)  
- Click the "Run War of the Chosen" button  
- If you want to use [my character pool](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=3752041602) (I recommend this, It will save you some time creating characters and will mean the random characters you get given aren't abominations. At least until they all die) click "CHARACTER POOL" on the main menu in game, then import character, select "Star Wars Pool 1", and press "IMPORT ENTIRE POOL"  
- I also recommend making some of your own characters in the pool so they can also show up in your game  
- Now you are ready to start a game (I recommend not using ironman and saving regularly as mods can introduce instability)  
  
Important Functionality You Should Know:  
-  [Galactic Ghost Templates](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=3580332608) and [Lightsaber Ghost Templates](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=2519711688) use ghost templates. To change your weapons to look like Star Wars weapons you will often have to click "RESKIN WEAPONS" in your character menu in the armoury. This is using a mod called [Xskin,](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=2337161588) if you go to the steam page for it there are some good videos that show you how to use it.  
- Playable Jedi are added using [Jedi Class Revived,](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=2031929512) but these classes are rare and require you to advance you character from a rookie without using the training facility.  
- On level up you get to pick from three classes with [Choose My Class.](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=1467643380) (This should make it a little easier to get a Jedi)  
- When selecting a character or enemy you can press F1 to see all stats and info for that unit using [Yet another F1](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=934236622)  
- The [Akimbo Class](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=1494158555) is also added which is a pistol dual wield class and is a lot of fun  
- There is [Free Camera Rotation.](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=616359783) I usually use Alt + Mouse movement to spin the camera to the angle I want.  
  
Features:  
- All Advent enemies are replaced with imperials from Star Wars with bounty hunter leaders using the [Advent to Galactic Empire](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=1395522281) mod  
- Lost are replaced with undead stormtroopers using [Death Troopers](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=1492389214)  
- There is a [Nightsister Third Party Faction](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=2850059924)  
- Everything else I could find that had a working replacer mod is replaced with Star Wars equivalents  
- There are also a few quality of life mods and enhancements  
  
  
If I was to change this I would replace the ghost template weapons with none ghost template ones and use [Rebel Weaponry Replacement](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=3475897927) so characters start with Star Wars Weapons, but I haven't tested this so haven't done that for this pack. I would also like to add the [Hutt third party faction](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=2621337093) and [Mandalorian third party faction](steam://openurl/https://steamcommunity.com/sharedfiles/filedetails/?id=2440032345) mods, but again I haven't tested them.  
  
All in all I found this playthrough very fun and would recommend this for anyone wanting a Star Wars playthrough of XCOM 2, or you could wait for [Star Wars: Zero Company.](steam://openurl/https://store.steampowered.com/app/2075800) I couldn't so I made this. Enjoy!
